ต้นทุนต่อ kg ของสินค้าคิดมาจากอะไร#

ต้นทุนต่อ kg = DM + DL + OH

  • DM (วัตถุดิบ) = สูตรการผลิต (BOM) × ราคาวัตถุดิบ ไล่จากชั้นล่างสุดขึ้นมา
  • DL (ค่าแรง) = อัตราค่าแรง × ชั่วโมงคนที่ใช้ผลิต 1 kg
  • OH (ค่าใช้จ่ายการผลิต) = อัตรา × ชั่วโมงเครื่องต่อ kg (แบบชั่วโมง) + อัตราต่อ kg (แบบกิโล)

อัตรา DL/OH ได้จากการ ปันค่าใช้จ่ายทั้งปี ลงเครื่องจักร: อัตรา = ค่าใช้จ่ายของ WC ÷ ฐานของ WC (ชั่วโมงเครื่อง / กก. / ชั่วโมงคน)

@@TRANCOUNT ไม่เป็น 0 / แก้แล้วคนอื่นไม่เห็น ทำยังไง#

SSMS ที่ใช้อยู่เปิดโหมด implicit transaction ไว้ ทุกคำสั่ง (แม้แต่ SELECT) จะเปิดทรานให้เองและค้างไว้จนกว่าจะสั่ง COMMIT ถ้าปิดหน้าต่างไป งานที่ทำอาจหายหมด และระหว่างนั้นตารางถูกล็อก

SELECT @@TRANCOUNT AS [ทรานที่เปิดค้าง];          -- ต้องได้ 0
SELECT CASE WHEN @@OPTIONS & 2 = 2 THEN 1 ELSE 0 END AS [implicit transaction];  -- 1 = เปิดอยู่

-- ดูว่าทรานเปิดมานานแค่ไหน และแก้ข้อมูลไปแล้วกี่รายการ
SELECT at.transaction_begin_time AS [เริ่มเมื่อ],
       dt.database_transaction_log_record_count AS [จำนวนการแก้ไข]
FROM sys.dm_tran_session_transactions st
JOIN sys.dm_tran_active_transactions at ON at.transaction_id = st.transaction_id
LEFT JOIN sys.dm_tran_database_transactions dt
       ON dt.transaction_id = st.transaction_id AND dt.database_id = DB_ID()
WHERE st.session_id = @@SPID;
  • จำนวนการแก้ไข = 0 → เป็นทรานว่าง COMMIT ได้เลย ไม่เสียอะไร
  • จำนวนการแก้ไข > 0 → ตรวจข้อมูลที่แก้ให้ถูกก่อน แล้วค่อย COMMIT (ไม่แน่ใจอย่า ROLLBACK)
COMMIT;
SET IMPLICIT_TRANSACTIONS OFF;   -- ปิดโหมดเฉพาะหน้าต่างนี้

ของขั้นตัวเอง (ต่อ 1 kg):

  • DL = 1 ÷ CapPerHour × Headcounts_shift × DLRate
  • OH แบบชั่วโมง = 1 ÷ CapPerHour × OHRate (RateHour)
  • OH แบบกิโล = OHRate (RateKG)
SELECT u.ItemCode, u.wc, u.MG, u.CapPerHour, u.Headcounts_shift,
       1.0 / NULLIF(u.CapPerHour, 0) * u.Headcounts_shift * h.DLRate AS [DL ต่อ kg],
       1.0 / NULLIF(u.CapPerHour, 0) * h.OHRate                    AS [OH ชม. ต่อ kg],
       k.OHRate                                                     AS [OH กก. ต่อ kg]
FROM cost.MGUSE u
LEFT JOIN COST_RateHour h ON h.MG = u.MG COLLATE DATABASE_DEFAULT
LEFT JOIN COST_RateKG   k ON k.MG = u.MG COLLATE DATABASE_DEFAULT
WHERE u.ItemCode = 'FG-0002';
