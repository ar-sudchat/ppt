10 · แผนงาน 6 เดือน

แผนดำเนินงาน 6 เดือนและเกณฑ์ตรวจรับ

ขอบเขตที่เสนอ: ติดตาม 5–10 ประเด็น เริ่มจาก 100–300 เว็บไซต์เป้าหมาย แล้วขยายเป็น 300–600 เว็บ ในครึ่งหลัง แจ้งเตือน 2 ช่องทาง และหน้าจอผู้บริหารเต็มรูปแบบ ทั้งนี้ ผู้บริหารเริ่มใช้หน้าจอจริงตั้งแต่สิ้นเดือนที่ 3

M1

วางรากฐาน

  • กำหนดประเด็นที่ติดตามร่วมกับหน่วยงาน
  • จัดทำรายชื่อเว็บเป้าหมายชุดแรก 100–300 เว็บ
  • ติดตั้งเครื่องและระบบพื้นฐานในศูนย์ข้อมูล
  • ออกแบบฐานข้อมูลและตัวดึงข้อมูล
M2

เก็บข้อมูลและตัดข่าวซ้ำ

  • ตั้งเวลาดึงหน้าเว็บตามข้อกำหนด robots.txt
  • แยกเนื้อหาหลัก จัดรูปแบบ และตัดข่าวซ้ำ
  • เชื่อม RSS, Sitemap และ Search API ชุดแรก
  • จัดทำชุดทดสอบมาตรฐาน 500–1,000 ชิ้น
M3จุดตรวจกลางทาง

ติดตั้ง AI และหน้าจอ

  • ติดตั้ง LLM ในหน่วยงาน ให้ผลแบบมีโครงสร้าง (JSON)
  • ให้คะแนนผลกระทบพร้อมเหตุผล
  • หน้าจอผู้บริหารและแจ้งเตือนทาง LINE/อีเมล
  • จุดตรวจกลางทาง และผู้บริหารเริ่มใช้งาน
M4

ขยายแหล่งข้อมูล

  • ขยายเว็บเป้าหมายเป็น 300–600 เว็บ
  • เพิ่มโซเชียลมีเดีย YouTube และเว็บบอร์ด ตามสิทธิ์ที่ได้รับ
  • เพิ่มแหล่งข้อมูลลิขสิทธิ์และ Search API ชุดที่สอง
  • หน้าจอสถานะแหล่งข่าวและระบบ
M5

Fine-tune รอบ 2 และวัดผล

  • เทรนจากข้อมูลที่เจ้าหน้าที่ยืนยันแล้ว
  • ขยายชุดทดสอบเป็น 2,000 ชิ้นขึ้นไป
  • รายงานความแม่นยำและอัตราแจ้งผิด เทียบก่อนและหลัง
  • ปรับเกณฑ์คะแนนตามการใช้งานจริง
M6ส่งมอบ

Fine-tune รอบ 3 และส่งมอบ

  • เทรนรอบสุดท้ายและกำหนดรุ่นโมเดลที่ใช้งาน
  • อบรมเจ้าหน้าที่และจัดทำคู่มือปฏิบัติการ
  • ส่งมอบซอร์สโค้ด ไฟล์โมเดล และเอกสาร
  • ตรวจรับตามเกณฑ์ (UAT)
ตรวจรับงานสิ้นเดือนที่ 6
กำหนดเกณฑ์ร่วมกันตั้งแต่เริ่มโครงการ และตรวจความก้าวหน้าสิ้นเดือนที่ 3 หากยังไม่ได้ตามเป้า ปรับแผนครึ่งหลังได้ทันที
