## แก้ไข

ไฟล์เดียวจบ ไม่มี generator — แก้ `index.html` ตรง ๆ

- **เพิ่ม/ลบสไลด์** = เพิ่ม `<div class="slidewrap"><div class="sheet" data-key="…">…</div></div>` แล้วเพิ่มบรรทัดใน `<nav>` ให้ตรงลำดับ (ตัวนับ 37 อยู่ใน `nav .head .t`) — **ลำดับใน nav ต้องตรงกับลำดับสไลด์เป๊ะ** เพราะสคริปต์จับคู่ด้วย index
- **อ้างเลขสไลด์ในเนื้อหา** มีหลายจุด (`สไลด์ 10/13/21/26/27/28/35`) — แทรกสไลด์แล้วต้องไล่แก้ด้วย `grep -o 'สไลด์ [0-9–]*'`
- **แอนิเมชัน**: เส้นไหลใช้คลาส `.flow` (เส้นประวิ่ง) · จุดกะพริบ `.glow` · จุดวิ่งรอบวงใช้ `<animateMotion>` · แถบเทียบก่อน/หลังใช้ `.cmp` + `--w` และเริ่มใหม่ทุกครั้งที่เปิดสไลด์ (คลาส `play` ที่ `.slidewrap`) · ทุกอย่างปิดเองเมื่อระบบตั้ง “ลดการเคลื่อนไหว”
- **ภาพจอจริง**: ห่อด้วย `<div class="shot"><img …></div>` — คลิกแล้วขยายเต็มจอเอง (lightbox `#lb`) · ข้อความใน `alt` ใช้เป็นคำบรรยายตอนขยาย
- คลาสที่ใช้: `.grid2/3/4` `.card2` `.qtbl` `.pill` `.steps` `.stats/.stat` `.mini` `.layers` `.cmp` `.dia` `.lgd` `.warnbox` `.okbox` `.infobox` `.subh` `pre.code` `.mono`

export NODE_PATH=$HOME/Beside-DEMO/xray-shots/node_modules

ตรวจว่าลำดับ nav ตรงกับสไลด์:

```bash
paste <(grep -o 'data-key="[a-z0-9]*"' index.html | sed 's/data-key="//;s/"//') \
      <(grep -o '^    <a href="#[a-z0-9]*"' index.html | sed 's/.*#//;s/"//') \
  | awk '$1!=$2{print "MISMATCH:",NR,$1,$2}'
```
